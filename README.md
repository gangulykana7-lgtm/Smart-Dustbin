# Smart-Dustbin

# Project Description
The Smart Dustbin is an automatic waste bin designed to open its lid when a person comes near it.

# Components Required
Arduino UNO
HC-SR04 Ultrasonic Sensor
Servo Motor
Battery and jumper wires
Bin

# Working Principle
The ultrasonic sensor detects an object nearby and sends distance information to the Arduino UNO. When an object is within the programmed distance, the servo motor opens the dustbin lid. After a short delay, the lid closes automatically.

# Applications
Homes
Colleges and offices
Hospitals
Public places
